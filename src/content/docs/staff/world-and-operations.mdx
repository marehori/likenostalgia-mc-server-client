# Мир, приваты и операции

## Open Parties and Claims для модератора

OpenPAC использует команды:

```text
/oclaims
/oparties
/opac
/opm <сообщение>
```

`/oclaims` — действия с приватами; `/oparties` — группы; `/opac` — настройки; `/opm` — чат группы. В версии сервера доступны только те подкоманды, которые показываются через `Tab` и выданы LuckPerms. Не снимай чужой приват и не меняй владельца «для удобства»: сначала проверь владельца, причину, согласие/правила и запись в Ledger.

У OpenPAC есть режимы администратора/модератора, позволяющие видеть/обходить защиту. Используй их только для проверки инцидента и выключай сразу после. В нормальной игре модератор не должен случайно ломать или открывать вещи игроков через bypass.

## Chunky: подготовка мира

```text
chunky world <dimension>
chunky shape square
chunky center <x> <z>
chunky radius <блоки>
chunky selection
chunky start
chunky progress
chunky pause
chunky continue
chunky cancel
```

На Fabric для обычного мира используй `chunky world minecraft:overworld`, а не имя папки мира. Перед `start` обязательно выполни `selection` и проверь измерение, форму, центр и радиус. `cancel` уничтожает текущую задачу — не путай его с `pause`.

Пример подтверждённой операции для центра `-94, -10`:

```text
chunky world minecraft:overworld
chunky shape square
chunky center -94 -10
chunky radius 4000
chunky selection
chunky start
```

Если хостинг перезапустил сервер, состояние задачи сохраняется; после проверки `chunky progress` продолжай `chunky continue`. На время pregeneration отключай плановые перезапуски и учитывай, что сервер может ставить мир на паузу, когда нет игроков.

## Vanilla-команды для инцидента

```text
/kick <ник> [причина]
/ban <ник> [причина]
/pardon <ник>
/tp <цель> <x> <y> <z>
/gamemode spectator <ник>
/gamemode survival <ник>
/spawnpoint <ник> [x y z]
/setworldspawn <x> <y> <z>
```

`kick` — кратковременно убрать игрока, обычно с понятной причиной. `ban` — только согласно политике сервера и с фиксацией доказательств; `pardon` снимает бан. `spectator` удобен для наблюдения за инцидентом без вмешательства, но перед возвращением игрока всегда ставь нужный режим явно. `tp` используй осторожно: убедись, что точка безопасна и не раскрывает чужую базу.

## Граница и правила мира

```text
/worldborder center <x> <z>
/worldborder set <диаметр>
/worldborder get
/gamerule minecraft:respawn_radius <значение>
```

Изменение границы/правил мира — административная операция. Выполняй её только в согласованное окно, документируй прошлое и новое значение, затем проверяй результат `worldborder get`. Для текущего мира центр и спавн были выбраны возле `-94, 64, -10`; не меняй их без решения владельца сервера.

## Перезапуск, конфиги и профилактика

Перед изменением серверного конфига останови сервер, сделай резервную копию конкретного файла, внеси минимальную правку и перезапусти. Не меняй клиентский `enchancement.json` на сервере «на глаз» и не обновляй один JAR в живой сборке: версии и конфиги должны оставаться согласованными с опубликованным клиентом.
