# Скачать клиент

Клиентский пакет Likenostalgia подготовлен для **Minecraft 26.2** с **Fabric Loader 0.19.3**. Если лаунчер не выберет Java сам, используйте **Java 25**.

<div class="sl-link-card">
  <a href="https://github.com/marehori/likenostalgia-mc-server-client/releases/latest">Открыть актуальный релиз на GitHub →</a>
  <p>В релизе ищите <code>Likenostalgia-26.2-Client-v1.1.zip</code>.</p>
</div>

## Что внутри

- готовый набор модов и их зафиксированные версии;
- общие конфиги, включая обязательный `config/enchancement.json`;
- Complementary Reimagined в `shaderpacks` — установлен, но выключен по умолчанию;
- Simple Voice Chat, Xaero’s Minimap и Xaero’s World Map;
- `servers.dat`, поэтому Likenostalgia уже будет в Multiplayer.

## Не кладите ZIP в папку с другой сборкой

Сделайте отдельный чистый профиль Minecraft. Не обновляйте и не удаляйте моды по одному: сервер и клиент используют согласованный набор версий.
