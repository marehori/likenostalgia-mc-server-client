# Изменения

## Клиент v1.0

Первая публичная версия клиентского пакета Likenostalgia.

- Minecraft 26.2;
- Fabric Loader 0.19.3;
- Java 25;
- согласованный набор модов и конфигов;
- обязательный `enchancement.json`;
- Simple Voice Chat, Xaero’s Minimap и Xaero’s World Map;
- Complementary Reimagined установлен, но выключен по умолчанию;
- сервер `likenostalgia.joinserver.ru` уже добавлен в Multiplayer.

Будущие изменения будут добавляться сюда вместе с новыми версиями клиента.
